# Pasta de Frames da Sequência de Scroll

Coloque aqui os seus **242 arquivos de imagem JPG** nomeados exatamente como:
- `frame-0001.jpg`
- `frame-0002.jpg`
- `frame-0003.jpg`
- ...
- `frame-0242.jpg`

O script `script.js` está configurado para ler automaticamente esta pasta (`./frames/frame-XXXX.jpg`).
Se as imagens ainda não estiverem nesta pasta, o sistema possui um motor gráfico de simulação procedimental neon embutido que gera o fluxo visual até que você cole os seus arquivos originais aqui!
